# Restaurant Reservation App

Αυτή η εφαρμογή επιτρέπει στους χρήστες να κάνουν κράτηση σε εστιατόρια, να δημιουργήσουν λογαριασμό, να συνδεθούν και να δουν τις κρατήσεις τους. Είναι χτισμένη με React και περιλαμβάνει όλα τα βασικά στοιχεία για διαχείριση χρηστών, εγγραφές και κρατήσεις τραπεζιών.

## Τεχνολογίες

- **Frontend**: React.js
- **State Management**: React Hooks (useState, useEffect)
- **CSS**: Για το στυλ και την εμφάνιση
- **LocalStorage**: Αποθήκευση δεδομένων χρηστών

## Περιγραφή

Η εφαρμογή αποτελείται από τις εξής βασικές λειτουργίες:

- **Εγγραφή Χρηστών**: Ο χρήστης μπορεί να δημιουργήσει νέο λογαριασμό.
- **Σύνδεση Χρηστών**: Ο χρήστης μπορεί να συνδεθεί με το λογαριασμό του χρησιμοποιώντας email και password.
- **Κράτηση Θέσεων**: Οι χρήστες μπορούν να κάνουν κρατήσεις σε εστιατόρια και να δουν τις υπάρχουσες κρατήσεις τους.
- **Αποσύνδεση**: Ο χρήστης μπορεί να αποσυνδεθεί από την εφαρμογή.
- **Λίστα Εστιατορίων**: Προβολή των διαθέσιμων εστιατορίων για κρατήσεις.

### Δομή Αρχείων

- `src/App.js`: Κύριο αρχείο της εφαρμογής, που περιλαμβάνει την λογική σύνδεσης, αποσύνδεσης και εμφάνισης της λίστας εστιατορίων.
- `src/components/LoginForm.js`: Φόρμα σύνδεσης.
- `src/components/RegisterForm.js`: Φόρμα εγγραφής.
- `src/components/ReservationForm.js`: Φόρμα για την κράτηση τραπεζιού.
- `src/components/RestaurantList.js`: Λίστα των διαθέσιμων εστιατορίων.
- `src/components/UserReservationsTable.js`: Προβολή των κρατήσεων του χρήστη.

## Εγκατάσταση

Ακολουθήστε τα παρακάτω βήματα για να ρυθμίσετε την εφαρμογή στον τοπικό σας υπολογιστή.

### 1. Εκκίνηση του Backend

Ανοίξτε ένα τερματικό και μεταβείτε στον φάκελο του backend:

```bash
cd desktop
cd restaurant
cd restaurant-backend
node server.js
```

### 2. Εκκίνηση του Frontend

Ανοίξτε νέο τερματικό και μεταβείτε στον φάκελο του frontend:

```bash
cd desktop
cd restaurant
npm start
```

Αυτή η εντολή θα ανοίξει την εφαρμογή στον προεπιλεγμένο περιηγητή σας (συνήθως στο [http://localhost:3000](http://localhost:3000)).

## Χρήση

1. **Εγγραφή Χρηστών**: Πληκτρολογήστε τα στοιχεία σας στην φόρμα εγγραφής για να δημιουργήσετε λογαριασμό.
2. **Σύνδεση Χρηστών**: Χρησιμοποιήστε τα στοιχεία σας για να συνδεθείτε.
3. **Κράτηση Θέσεων**: Επιλέξτε από τη λίστα των εστιατορίων και κάντε κράτηση.
4. **Διαχείριση Κρατήσεων**: Μπορείτε να δείτε τις υπάρχουσες κρατήσεις σας.
5. **Αποσύνδεση**: Πατήστε το κουμπί αποσύνδεσης για να αποσυνδεθείτε.

## Σχεδιασμός και Χρήση LocalStorage

Η εφαρμογή αποθηκεύει το token και το όνομα χρήστη στο **localStorage** για να παραμένει συνδεδεμένος ο χρήστης κατά τη διάρκεια των συνεδριών. Αν ο χρήστης αποσυνδεθεί, αυτά τα δεδομένα διαγράφονται.

## Συμβουλές και Σφάλματα

- Αν συναντήσετε οποιοδήποτε πρόβλημα κατά τη διάρκεια της ανάπτυξης ή της χρήσης, ελέγξτε το κονσόλα του προγράμματος περιήγησης για σφάλματα JavaScript.
- Βεβαιωθείτε ότι το API backend που υποστηρίζει τις λειτουργίες κράτησης και εγγραφής είναι ενεργό και λειτουργεί σωστά.

## Backend (Node.js + Express + MariaDB)

Ο φάκελος `restaurant-backend` περιέχει τον backend κώδικα της εφαρμογής. Ο server υλοποιεί τα παρακάτω API endpoints:

- `POST /register`, `POST /login`: Αυθεντικοποίηση χρηστών με JWT
- `POST /reservations`, `GET /reservations/user`, `PUT /reservations/:id`, `DELETE /reservations/:id`: Διαχείριση κρατήσεων
- `POST /restaurants`, `PUT /restaurants/:id`, `DELETE /restaurants/:id`: Διαχείριση εστιατορίων


Ο backend απαιτεί MariaDB βάση δεδομένων με τους πίνακες `users`, `restaurants` και `reservations`.

## Δοκιμές με Postman

Ο φακελός περιλαμβάνει το αρχείο `Restaurants.postman_collection.json` με όλα τα API αιτήματα της εφαρμογής. Το αρχείο περιλαμβάνει αιτήματα για:

- Εγγραφή και σύνδεση χρηστών
- CRUD κρατήσεων
- CRUD εστιατορίων

Μπορεί να εισαχθεί απευθείας στο Postman για δοκιμές.

## Εισαγωγή Βάσης Δεδομένων

Η βάση δεδομένων της εφαρμογής έχει εξαχθεί σε αρχείο SQL και περιλαμβάνεται στον φάκελο:

```
restaurant-backend/database/restaurant_db.sql
```

### Οδηγίες εισαγωγής:

1. Δημιουργήστε μια νέα βάση δεδομένων με όνομα `restaurant_app` 
2. Εισάγετε το αρχείο `.sql` μέσω phpMyAdmin ή μέσω της γραμμής εντολών:
   ```bash
   mysql -u root -p restaurant_db < restaurant_db.sql
   ```
3. Η βάση περιλαμβάνει τους πίνακες:
   - `users`
   - `restaurants`
   - `reservations`
4. Περιλαμβάνονται επίσης ενδεικτικά δεδομένα για δοκιμές
